# pairclear/.github

Organisation profile and default community files for [github.com/pairclear](https://github.com/pairclear).

- `profile/README.md`: the profile shown on the organisation page, plus its banners, avatar and social preview.
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`, `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md`: defaults for every repo in the organisation that has no file of its own.
